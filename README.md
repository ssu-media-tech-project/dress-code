# 옷입히기 게임

“계절을 입어요.”
이 게임은 단순히 옷을 입히는 게 아니라, 지금 이 순간의 계절감과 감정을 표현하는 경험이에요.

봄이면 부드럽게 흩날리는 벚꽃 속에서,  
여름이면 눈부신 햇살 아래 시원한 린넨을,  
가을이면 낙엽이 스치는 골목의 따뜻한 니트를,  
겨울이면 눈 내리는 저녁의 포근한 코트를.

플레이어는 네 가지 계절 중 하나를 선택해,  
3D 아바타에게 어울리는 옷과 색을 입힙니다.

모든 조합은 실시간으로 점수화되어,  
“조화도”, “계절감”, “스타일 완성도”에 따라  
당신의 감각이 패션 점수로 표현돼요.
